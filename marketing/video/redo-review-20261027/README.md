# Four-video replacement review

The images in `final-encoded/` were extracted from the replacement MP4s after encoding. `final-encoded/verification.json` binds each frame to its video hash and timestamp and summarizes independent technical QA. These are the final-file review images to use in the pull request.

The top-level stills and `review-manifest.json` are earlier design checkpoints, generated by `render_stills.py`; they are not evidence of the final encode. `cue-timeline.json` is the relative-source edit map used by the renderer.

The replacements have clean illustrated game menus, individual cue captions, per-pack destinations and a native portrait layout. The sound effects use procedural DSP; code, video and text were AI-assisted. The illustrative interface is not included with the packs. Audio was composed from the named source recordings, not newly captured from Godot.

GB must watch all four complete replacements before creative acceptance. The earlier batch remains rejected for upload. Technical checks and muted browser playback do not establish physical listening, owner acceptance or permission to publish.
